Questions

Is it really free?

Yes. No file limit, no size cap, no trial. Finding folders that hold the same files, in the same places, as another folder is free too. There is one optional extra, Backup Cleanup, for getting your space back from old backup folders and drives: 14.99 US dollars once, or 4.99 US dollars a month. Skip it and nothing is hidden or greyed out.

How does it decide two files are copies?

It reads them. It looks at files of the same size, reads a small part of each to rule out the ones that differ, and compares every byte of what is left. Never by file name.

Where do the files go?

The Recycle Bin. You can put them back until the bin is emptied. Before the move starts, each file is compared again with the copy that stays. A file that no longer matches is kept. The app says so before a clean-up that is too big for the Recycle Bin starts: The total size is more than your Recycle Bin can hold, so Windows may permanently remove some items to make room. These can include older items already in the bin and files from this job.

Can it delete every copy by mistake?

The app refuses to remove the last copy of a set, and says so on screen.

Does it find photos that look alike?

The scan itself only reports files where every byte matches. A picture saved again at a different size is a different file. Inside the optional Backup Cleanup plan there is a look-alike photo check that suggests the higher-resolution copy and ticks nothing for you.

Can it clean up old backup folders and drives?

Yes, with the optional Backup Cleanup. It shows how much of each folder is also in the others, shows you the plan before anything moves, copies each file you do not already have and compares it with the original, and sends the old folder to the Recycle Bin only when nothing in it is missing from what you keep. Removal needs a drive with a Recycle Bin. Most USB sticks, SD cards and network drives have none, so they are compared but not cleaned.

Does it send anything anywhere?

No. No account, no tracking, and the app makes no network connections. See the privacy policy.

What does it leave alone?

This PC's Windows, Program Files and Store app folders. A repeated file there is usually meant to be there.
