Questions

Is it really free?

Yes. No file limit, no size cap, no trial. There is one optional extra, Duplicate Folders, at 24.99 US dollars once. Skip it and nothing is hidden or greyed out.

How does it decide two files are copies?

It reads them. Files are grouped by exact size, a small part of each is read to rule out coincidences, and what is left is compared byte for byte. Never by file name.

Where do the files go?

The Recycle Bin, so you can put them back. Each file is checked against the disk again just before it is removed, and anything that changed since the scan is kept instead.

Can it delete every copy by mistake?

No. One copy of every set always stays. The app refuses the last tick and says so on screen.

Does it find photos that look alike?

No. A picture saved again at a different size is a different file, and this app only reports files that match byte for byte.

Does it send anything anywhere?

No. No account, no telemetry, no network connection. See the privacy policy.

What does it leave alone?

Windows, Program Files and the Store app folder. A repeated file there is usually meant to be there.
